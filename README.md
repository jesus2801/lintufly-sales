# LINTUFLY - Sales

This is a no longer maintained project whose goal was to help businesses in decision-making with statistics of sales and useful dashboards.

## Thecnologies

This project uses NextJS with typescript, NodeJS with Fastify, and GraphQl. It has integrated tests for speed in order to achieve a high response rate in case of increasing demand.
